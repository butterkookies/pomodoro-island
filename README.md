## Overview

Pomodoro Island transforms the classic focus technique into an unobtrusive, ambient desktop presence. Designed with extreme restraint, it anchors seamlessly into your monitor's top bezel—flowing between three fluid states with physical acoustic feedback and tactile 3D controls.

- **Deep Black Obsidian**: Pure `#000000` canvas with zero colored borders, zero neon glow, and zero visual clutter.
- **Physical Depth**: Ceramic 3D buttons with specular highlights, physical drop shadows, and recessed squircle tracks.
- **Inter Typography**: Tabular numerals throughout ensure smooth, jitter-free countdown transitions.
- **Seamless Notch Flares**: Symmetrical concave ears integrate naturally with display bezels.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/butterkookies/pomodoro-island.git
cd pomodoro-island

# Install dependencies
npm install

# Run in development
npm run dev

# Build production application
npm run build
```
